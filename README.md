# email_webapp

A Flask-based web application for sending and receiving emails with automatic spam detection powered by a machine learning classifier.

---

## Features

- Register and log in with your Gmail account
- Compose and send emails via SMTP
- Sync and view your inbox via IMAP
- Automatic spam classification using a trained MLP model
- Separate inbox and spam folder views

---

```
    ├── login.html
    ├── register.html
    ├── compose.html

```

## Requirements

- Python 3.9+
- A Gmail account with [App Passwords](https://support.google.com/accounts/answer/185833) enabled

Install dependencies:

```bash
pip install flask aiosmtpd scikit-learn pandas joblib
```

## Setup

### 1. Get the dataset

Download a spam/ham email dataset and save it as `spam_ham_dataset.csv` in the project root. The file must have two columns:

| Column | Values |
|--------|--------|
| `text` | raw email text |
| `label` | `spam` or `ham` |

A good dataset to use: [SMS Spam Collection on Kaggle](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset).

### 2. Train the model

```bash
python train.py
```

This will output `spam_model.joblib` and `vectorizer.joblib` and print accuracy and a full classification report.

### 3. Run the app

```bash
python app.py
```

The app will be available at `http://localhost:5000`.

### 4. (Optional) Run the SMTP receiver

If you want to receive emails through the built-in SMTP server instead of Gmail IMAP:

```bash
python smtp_receiver.py
```

By default it listens on `0.0.0.0:8025`. Configure with environment variables:

```bash
SMTP_RECEIVER_HOST=0.0.0.0
SMTP_RECEIVER_PORT=8025
```

---

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `SMTP_HOST` | `smtp.gmail.com` | SMTP server for sending emails |
| `SMTP_PORT` | `587` | SMTP port |
| `SMTP_RECEIVER_HOST` | `0.0.0.0` | Host for the built-in SMTP receiver |
| `SMTP_RECEIVER_PORT` | `8025` | Port for the built-in SMTP receiver |
| `SPAM_MODEL_PATH` | `spam_model.joblib` | Path to the trained model file |
| `VECTORIZER_PATH` | `vectorizer.joblib` | Path to the trained vectorizer file |

## How the Spam Classifier Works

1. Incoming emails are passed through a **TF-IDF vectorizer** that converts the text into numerical features, scoring words by how distinctive they are across all emails.
2. The feature vector is fed into a **Multi-Layer Perceptron (MLP)** with two hidden layers (128 and 64 neurons).
3. The model outputs a label (`spam` or `normal`) and a confidence score.
4. Emails are stored in SQLite and separated into inbox and spam views accordingly.

---

## Usage

1. Open `http://localhost:5000` and register with your Gmail address and Gmail App Password.
2. Use **Compose** to send an email.
3. Open **Inbox** to sync and view your normal emails.
4. Open **Spam** to view emails the classifier flagged as spam.
